# Flight Assistant v0.1.5 — én API-konfigurasjon for alle reiser

- **Første installasjonsskjerm:** Velg datakilde: «Automatisk», «Kun Avinor» eller «AeroDataBox + Avinor».
- **API-nøkkel** legges inn bare i hovedoppsettet, og er nødvendig kun hvis du velger «AeroDataBox + Avinor». «Automatisk» og «Kun Avinor» kan brukes uten nøkkel.
- Alle reiser og tilhørende enheter **arver samme valg og nøkkel**; API-felt vises aldri når du legger til eller ser på enheten.
- Under **Flight Assistant → Konfigurer** kan du endre datakilde/nøkkel uten å slette reiser.
- «Kun Avinor» sender ingen AeroDataBox-forespørsler, selv med lagret nøkkel.
- Alle øvrige reisefelt, mellomlandinger, buss/tog/bil/taxi og avreiseforslag er beholdt.

**Fortsatt begrenset:** Flynummer/dato må identifiseres; PNR- og e-postimport er ikke aktivert. Gratis API-nivå må velges og administreres av brukeren. Release er kontrollert med Python-tester, ikke ennå testet i en reell Home Assistant-installasjon.
