# Flight Assistant v0.1.2 — gratis flyoppslag langt frem

### Nytt

- Registrer **en navngitt reise med flynummer + avreisedato**, uten bookingreferanse eller etternavn.
- Legg til opptil åtte flystrekninger ved flybytte; enheten og informasjonen lagres i Home Assistant.
- Valgfri **AeroDataBox RapidAPI Basic**-nøkkel under **Flight Assistant → Konfigurer** for flightnummer/dato-oppslag langt frem i tid (RapidAPI oppgir inntil 365 dagers søkehorisont, men reelle rutetider avhenger av dekning og tilgjengelighet).
- Uten API-nøkkel kan reiser lagres. **Avinor** forsøkes innen 14 dager for norske flyplasser; angi helst avreiseflyplass for sikker matching. Ved manglende IATA-kode sjekkes kun fem større lufthavner.
- Rutetider fra AeroDataBox, med norsk gate og innsjekkingsområde fra Avinor når tilgjengelig nær avreise.
- Sensordata for hver reise og nedtelling; «Neste flyreise» finner også gjenkjente strekninger.
- Alle treff merkes med kilde. Ukjente/ambivalente treff merkes som uavklart, ikke som verifiserte bookinger.

### Gratiskvote

AeroDataBox RapidAPI Basic er oppført med **0 USD/mnd, 400 API-enheter og hard månedlig grense**. Flight Status er et Tier 2-oppslag og bruker normalt **2 enheter per forespørsel**. Integrasjonen forsøker ikke å opprette konto, oppgradere abonnementsnivå eller ta betalt. Du må selv registrere deg på gratisplanen og kontrollere RapidAPIs vilkår (inkludert betalingskort og eventuell båndbreddekostnad). Oppslag begrenses og gjenbrukes i opptil seks dager, og det hentes ikke live GPS-flyposisjon fra denne kilden.

### Fremdeles ikke inkludert

- Direkte PNR/etternavn-oppslag hos SAS eller Norwegian.
- Automatisk e-postimport.
- Kart med faktisk flyposisjon.
- Bekreftelse av passasjerens innsjekkingsstatus.
- Garantert internasjonal rutedekning eller garanti for flytider måneder frem.

**Status:** Python-syntaks og enhetstester på GitHub er bestått. Ingen reell API-nøkkel eller Home Assistant OS-installasjon er end-to-end-testet. Bekreft viktige flydata hos flyselskapet. Ta backup av Home Assistant før oppdatering.
