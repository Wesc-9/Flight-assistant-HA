# Flight Assistant v0.1.4 – nytt installasjonsoppsett

- **Skjerm 1:** AeroDataBox RapidAPI-nøkkel. Valgfri for Avinor-basert gratisbruk; ingen API-test som bruker kvote under installasjon.
- **Skjerm 2:** Legg inn første reise automatisk etter oppsettet, uten å lete etter «Legg til reise».
- Felter i reiseskjermen: **Navn, flynummer, dato, mellomlanding, innsjekket bagasje, transportmåte, avreiseadresse, innenlands/utenlands, ankomstmargin nederst**.
- Flyselskapet utledes fra flynummeret: **SK → SAS, DY/D8 → Norwegian, WF → Widerøe**.
- Huk av mellomlanding for å legge inn flere flystrekninger; maks 8.
- Transportvalg: gå, buss, taxi, tog, kjøre selv, sammenlign bil/kollektiv, all kollektiv eller sykle.
- **Buss/tog:** Entur-ruter med valgt kjøretøy. **Taxi/bil:** Waze, men taxioppslag tar ikke med bestilling/ventetid. Gange/sykkel har fortsatt ikke ruteberegning.
- Eksisterende Flight Assistant-installasjoner beholdes og oppdateres via HACS. Nøkkelen redigeres under «Konfigurer», og reiser opprettes via «Legg til reise». Ikke opprett ekstra hovedintegrasjon.
- API-oppslag med flynummer/dato og flyplassstatus gjelder fortsatt. PNR-oppslag er ikke aktivert.

**Status:** Automatiserte Python-tester kan bekrefte syntaks og ren logikk, men Home Assistant-grensesnittet og API-tilkoblinger må fortsatt testes i din HA OS-installasjon. Bruk flyselskapets egen informasjon når avgang er nært forestående.
